What it is

VulnPath-AI is a local Python scanner aimed at the glue code around agents and tools: secrets in source, unsafe shell use, eval/exec, pickle, SSRF-style fetches, path issues, and SQL string building.

  • Hybrid detection (patterns + Python AST)
  • Source→sink style path context where possible
  • Markdown / JSON / SARIF reports
  • Optional YAML rule packs
  • Optional --apply-fix only with explicit permission

What it is not

  • Not a full enterprise SAST replacement
  • Not an exploit or attack toolkit
  • Not a guarantee of zero false positives/negatives

Treat findings as leads for human review.
